# MTS Framework — Wiki

The MTS Framework is a Ren'Py sandbox framework for management games with locations, events,
characters, stats, situations, unlockables, a journal and a paperdoll system.

## 🛠️ For Developers & Modders

→ Start at the **[Developer Overview](Developer-Guide)**. Want to help? See
**[How to Contribute](How-to-Contribute)**. The main guides:

- **[Events](Events)** — how events are registered, selected and played.
- **[Building Situations](Building-Situations)** — the bidirectional-bar system for
  ongoing storylines.
- **[Building Unlockables](Building-Unlockables)** — rules, clubs and building unlocks
  via the PTA vote.
- **[Dialogue](Dialogue)** and **[Paperdoll](Paperdoll)** — characters on screen.

## 🎛️ Tools

The in‑game **[Cheat Menu](Cheat-Menu)** — jump events, drive situations, force
unlockables, edit stats and time, and inspect the save. Useful for testing.
**Read its dangers section before using it.**

## Example content

The framework ships with a minimal example so it starts and shows how things fit
together: one student (`jane_doe`), the secretary (`secretary`), two buildings
(School Building, Office Building), one event (`example_event`), one situation
(`example_situation`), one unlockable and two items. Replace them with your own.
